# Utiliser les structures pour organiser des données liées

Une _struct_ (ou structure) est un type de données personnalisé qui vous permet de regrouper et de nommer plusieurs valeurs liées entre elles, formant ainsi un ensemble cohérent. Si vous connaissez un langage orienté objet, une structure ressemble aux attributs de données d’un objet. Dans ce chapitre, nous comparerons les tuples et les structures afin de nous appuyer sur vos connaissances et de montrer dans quels cas les structures sont préférables pour regrouper des données.

Nous verrons comment définir et instancier des structures. Nous aborderons la définition de fonctions associées, en particulier celles appelées _méthodes_, qui permettent de spécifier le comportement associé à un type de structure. Les structures et les énumérations (présentées au chapitre 6) sont les éléments de base permettant de créer de nouveaux types adaptés au domaine de votre programme et de tirer pleinement parti de la vérification des types à la compilation de Rust.
