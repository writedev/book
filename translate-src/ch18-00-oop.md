# Fonctionnalités de la programmation orientée objet

<a id="object-oriented-programming-features-of-rust"></a>

La programmation orientée objet (POO) est une façon de modéliser les programmes. Les objets, en tant que concept de programmation, ont été introduits dans le langage de programmation Simula dans les années 1960. Ces objets ont influencé l’architecture de programmation d’Alan Kay, dans laquelle les objets s’envoient des messages. Pour décrire cette architecture, il a forgé le terme _programmation orientée objet_ en 1967. De nombreuses définitions concurrentes décrivent ce qu’est la POO ; selon certaines, Rust est orienté objet, tandis que selon d’autres, il ne l’est pas. Dans ce chapitre, nous examinerons certaines caractéristiques généralement considérées comme propres à la programmation orientée objet et verrons comment elles se traduisent dans un code Rust idiomatique. Nous vous montrerons ensuite comment implémenter un modèle de conception orienté objet en Rust et discuterons des compromis liés à cette approche, par rapport à une solution qui tirerait parti de certaines des forces de Rust.
