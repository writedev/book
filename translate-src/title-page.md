# Le langage de programmation Rust

_par Steve Klabnik, Carol Nichols et Chris Krycho, avec la contribution de la
communauté Rust_

Cette version du texte suppose que vous utilisez Rust 1.97.0 (publié le 9 juillet 2026)
ou une version ultérieure, avec `edition = "2024"` dans le fichier *Cargo.toml* de tous les projets
afin de les configurer pour utiliser les idiomes de l’édition 2024 de Rust. Consultez la [section « Installation » du chapitre 1][install]<!-- ignore --> pour savoir comment installer ou
mettre à jour Rust, et consultez [l’annexe E][appendix-e]<!-- ignore --> pour obtenir des informations
sur les éditions.

La version HTML est disponible en ligne à l’adresse
[https://doc.rust-lang.org/stable/book/](https://doc.rust-lang.org/stable/book/)
et hors ligne avec les installations de Rust effectuées avec `rustup` ; exécutez `rustup doc
--book` pour l’ouvrir.

Plusieurs [traductions] communautaires sont également disponibles.

Ce texte est disponible en [version papier et ebook chez No Starch
Press][nsprust].
